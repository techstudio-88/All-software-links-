# StudioShelf — Software Project Showroom

A public portfolio for exploring software projects without exposing source code or downloadable project files.

## Features
- Project cards, search and category filters
- Individual project detail view
- 30 interface-preview concepts per project, rendered from reusable UI mockups
- Browser speech synthesis narration (no uploaded audio required)
- Technology, audience, repository size and status details
- UPI payment intent link for purchase enquiries

## Important preview and payment notes
The 30 screens per project are generated interface concepts, not screenshots captured from a running copy of each application. They are not a substitute for a live product demo. Repository status notes are based on available project documentation and should be reconfirmed before a sale.

The UPI button opens a payment intent for `8859985492@axl`. It does not verify payment, unlock files or deliver source code automatically. Confirm scope, price, ownership transfer, setup and support terms with the buyer before accepting payment.
