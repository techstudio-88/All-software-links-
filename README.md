# StudioShelf — Software Project Showroom

A public portfolio for exploring software projects without exposing source code or downloadable project files.

## Features
- Project cards, search and category filters
- Individual project detail view
- 30 interface-preview concepts per project, rendered from reusable UI mockups
- Browser speech synthesis narration (no uploaded audio required)
- Technology, audience, repository size and status details
- WhatsApp project-request links and direct email contact
- Automatic discovery of public GitHub repositories every five minutes
